# 🛒 ShopMetrics — ECommerce Dashboard (Practice Project)

A full Angular 17 e-commerce dashboard with **10 intentional bugs** for developer practice.

## 🚀 Quick Setup

```bash
npm install
npm start
# Open http://localhost:4200
```
